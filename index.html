案例概览

从公开招聘页面出发，完成一场从非结构化文本到薪资洞察的数据处理。

这个案例不是只做简单的数据下载，而是把页面中的非结构化信息转换成可以回答问题的数据。采集只是起点，更重要的环节在清洗、统计与挖掘。

我提取了职位、薪资、公司、地区和任职要求等字段，统一薪资格式并完成重复判断，再按行业、学历、经验、地区四个维度展开分析，最终形成一套可复用的数据采集与挖掘方法。

数据采集

03

分析发现

从 938 条招聘记录中提炼出的几个明显信号。

入门岗位

低门槛岗位也有不错回报

外卖配送、网约车、娱乐门店等不限学历经验的岗位，薪资区间并不低于部分办公室职位。

技能岗位

技能带来的溢价很明显

按摩师、美容师、技术工程师等技能型岗位收入显著更高，部分技能溢价可达 50%-100%。

办公室岗位

文职稳定，但薪资上限偏低

行政、客服、文员等岗位薪资区间较窄，福利和稳定性更突出，但收入成长空间有限。

管理技术岗

高薪岗位多来自管理与技术

销售管理、门店经理、技术工程师等岗位代表市场薪资天花板，通常需要多年经验积累。

灵活就业

灵活就业岗位正在增多

居家直播、陪诊、台球助教等新形态岗位持续出现，为不同背景的求职者提供更多选择。

求职提醒

看清薪资构成再作决定

薪资中可能包含绩效与补贴，需要确认保底金额；正规岗位通常不设入职费用。

04

技术方案

模块化的数据采集与处理链路，让每一步都可以单独验证和复用。

Python 3 数据处理 Scrapy 页面采集 Pandas 清洗统计 NumPy / SciPy 数值计算 Matplotlib 可视化 JSON Lines 结构化存储
01

页面采集与字段抽取

jobs.py

通过 XPath 提取职位标题、薪资、公司、地区与任职要求，并支持多页面遍历和重复判断。

02

统一数据模型

items.py

用一份稳定的字段模型承接采集、清洗与统计，避免不同环节之间出现口径偏差。

03

清洗与标准化

final_clean.py

完成 HTML 实体解码、字段修复、薪资范围解析和文本清理，把原始信息转换为可分析表格。

04

去重与数据存储

pipelines.py

以标题、薪资、公司、地点组成唯一标识进行去重，并把每条记录以 JSON Lines 形式写入。

05

统计与数据挖掘

data_analysis.py

按四个分析维度计算薪资统计量，结合 SciPy 与 Pandas 得到可比较的市场结论。

06

图表输出

Matplotlib

输出核密度、气泡、阶梯、雷达、箱线等五类专业图表，形成完整分析报告。
